
 Agrinho 2026 — Cultivo Hidropônico e Aquaponia

Objetivo

Este projeto foi desenvolvido para o Concurso Agrinho 2026, categoria Programação Front-End, com o tema: "Cultivo Hidropônico e Aquaponia: Alternativas Sustentáveis para o Futuro da Alimentação".

O site apresenta, de forma interativa e acessível, como os cultivos sem solo podem transformar a produção de alimentos no Brasil e no mundo.

Tecnologias Utilizadas

| Tecnologia | Uso |
| HTML5 | Estrutura semântica e acessível |
| CSS3 | Variáveis, Flexbox, Grid, animações, media queries |
| JavaScript ES6+ | Manipulação do DOM, Canvas API, IntersectionObserver, localStorage |

Importante: não foram utilizadas bibliotecas, frameworks ou códigos inline. Todo o CSS e JavaScript estão em arquivos separados, conforme exigido pelo regulamento do concurso.

Estrutura



├── index.html          # Página principal (one-page com âncoras)
├── style.css           # Estilos, animações e responsividade
├── script.js           # Interatividade, simulador, calculadora e tema
└── README.md           # Este arquivo


Funcionalidades

- Modo Escuro/Claro: alternância de tema com persistência no localStorage
- Ajuste de Fonte: botões para aumentar e diminuir o tamanho da fonte do site
- Calculadora de Economia de Água: simulação de economia hídrica com base na área de cultivo
- Simulador Interativo do Ciclo Aquapônico: etapas clicáveis que demonstram o fluxo Peixes → Bactérias → Plantas → Água Limpa
- Animações de Scroll: elementos que surgem conforme a rolagem da página
- Contadores Animados: números que crescem ao entrar na viewport
- Navegação Fixa e Fluida: menu com scroll suave e menu hambúrguer animado para dispositivos móveis
- Animações de Background: partículas em Canvas (bolhas de oxigênio) e ondas decorativas em SVG puro


Como Usar

1. Faça o download ou clone este repositório.
2. Abra o arquivo index.html em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
3. Navegue pelas seções usando o menu superior ou a rolagem da página.
4. Interaja com o simulador, a calculadora e os controles de acessibilidade.


 Acessibilidade

- Uso de tags semânticas (nav, main, section, article, button, label, input)
- Contraste de cores adequado para leitura
- Controles de tema e tamanho de fonte para melhor adaptação do usuário
